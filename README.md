# Хранители знания

Интерактивное комплексное задание по истории Казахстана для 8–11 классов (проблемный вопрос, источники, конструктор аргументации, рубрика, КСП).

## Публикация на GitHub Pages
1. Создайте репозиторий и загрузите `index.html` и `README.md` в корень.
2. Settings → Pages → Source: ветка `main`, папка `/ (root)`.
3. Сайт откроется по адресу `https://<имя-пользователя>.github.io/<репозиторий>/`.

Сайт работает без сборки и внешних библиотек. Цели обучения указаны по типовой программе «История Казахстана» (приказ МП РК от 16.09.2022 № 399, ред. от 21.11.2022 № 467); даты в карточках уточняйте по действующему учебнику.
